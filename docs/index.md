TiKòb Architecture Documentation

Audience: Senior Architects, Engineering Managers, and Principal Engineers.

Purpose

This documentation folder captures high-level architecture, design rationale, and operational guidance for TiKòb — the Global Community Savings Platform. The content is derived from the project README and organized to support design reviews, onboarding, and operational handoffs.

Scope

- Project overview and goals
- Key architectural diagrams (context, containers, sequence, data flow)
- Data flow and ledger model summary
- Security and operational considerations
- Architecture Decision Records (ADRs)

How to use this folder

- Start at this index for a consolidated summary.
- Read the project brief under /docs/projects/tikob.md for product-level context.
- Review /docs/architecture/* for diagrams, dataflow, and security considerations.
- Consult /docs/adrs for formalized architecture decisions; ADR-001 captures the ledger design decision.

Source of truth

The README in the repository is the single source of truth for feature scope, core models, and the project technology stack. This docs set extracts and structures that information for architectural consumption.
